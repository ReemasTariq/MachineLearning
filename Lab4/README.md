In this assignment, the Ames Housing dataset was analyzed and preprocessed. 
Data quality issues such as missing values, duplicated rows, and outliers were examined. 
Missing values were handled using mean imputation for numerical columns and mode imputation for categorical columns.
Outliers were detected and removed using the IQR method. 
Numerical features were normalized using both Min-Max scaling and Z-score standardization. Finally, PCA was applied after confirming the presence of correlation among numerical features.
