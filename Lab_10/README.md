In this lab, we used the Support Vector Machine (SVM) algorithm to classify the Iris flower dataset. We started by loading and exploring the dataset using Pandas and Seaborn, then created visualizations such as Pairplot and KDE Plot to better understand the relationships between the flower features and species. After that, we split the dataset into training and testing sets, trained the SVM model using Scikit-learn, and used it to make predictions. Finally, we evaluated the model’s performance using the Confusion Matrix and Classification Report, and improved the model accuracy by applying GridSearchCV to find the best values for parameters such as C and gamma.
